# ShopEase E-commerce Demo

## Run in VS Code
1. Extract this ZIP.
2. Open the `shopease-ecommerce-v2` folder in VS Code.
3. Open Terminal > New Terminal.
4. Run `npm install`
5. Run `npm run dev`
6. Open the local URL shown in the terminal (usually http://localhost:5173).

## Features
Home, product listing, search, category filter, sorting, product detail, cart, wishlist, checkout demo, order confirmation, login/register demo, account page and custom 404 route. Cart and wishlist persist with LocalStorage.

This is a frontend demonstration only. It has no backend, secure authentication, real payment processing or email delivery. Product images are loaded from Unsplash and need internet access.
